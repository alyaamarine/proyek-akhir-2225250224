# Proyek Akhir Algoritma & Pemrograman - Kalkulator Geometri

Aplikasi berbasis terminal (console) menggunakan Python untuk menghitung luas dan keliling bangun datar secara otomatis serta menyimpan riwayat perhitungannya.

## Cara Menjalankan Program (Pertemuan 15)
1. Buka terminal di VS Code.
2. Jalankan perintah: `python src/main.py`
